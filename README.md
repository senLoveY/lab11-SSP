# Ollama Lab

Лабораторная работа по интеграции локальных LLM. Консольное меню и интерфейс в браузере используют один C# клиент Ollama.

## Запуск на macOS и Windows

Понадобятся .NET 10 SDK и Ollama. Открой терминал в папке `OllamaLab`. Запусти Ollama командой `ollama serve`, если сервер ещё не запущен. Установленные модели показывает `ollama list`.

```shell
dotnet run --project OllamaClient -- --web
```

Открой [http://127.0.0.1:5080](http://127.0.0.1:5080). Чтобы вернуться к консольному меню, запусти `dotnet run --project OllamaClient`.

В Windows можно открыть `OllamaLab.sln` в Visual Studio 2026 или запускать проект из PowerShell. В Parallels открой ту же папку через общие папки Mac. Если Ollama работает на Mac, запусти его на IP-адресе интерфейса Parallels и перед запуском проекта в PowerShell задай адрес этого сервера. Для сети Parallels с адресом Mac `10.211.55.2` команды будут такими.

На Mac, в отдельном терминале

```bash
OLLAMA_HOST=10.211.55.2:11434 ollama serve
```

В PowerShell внутри Windows

```powershell
$env:OLLAMA_BASE_URL = "http://10.211.55.2:11434"
dotnet run --project OllamaClient -- --web
```

## Проверка функций

| Режим | Что проверить |
| --- | --- |
| Генерация | Нажми «Вставить пример». Запусти с включённым и выключенным «Потоковым выводом». |
| Чат | Вставь пример, отправь его и спроси «Обработай пустой массив в этом же методе». В ответе можно сверить имя `FindPeak`. |
| Ревью | Вставь пример `FindMax`. Инициализация максимума нулём даёт неверный ответ для массива отрицательных чисел. |
| Конвейер | Запусти пример с Фибоначчи. В результате появятся генерация и её ревью. |

В каждом режиме запросы и ответы идут в одной ленте. При её прокрутке навигация, выбор модели и поле ввода остаются на месте. Только режим «Чат» передаёт предыдущие реплики модели.

Отправить запрос с клавиатуры можно через `Ctrl+Enter` или `⌘+Enter`. Если прокрутить ленту вверх, кнопка «К последнему сообщению» вернёт к концу переписки.

Веб-интерфейс форматирует Markdown по мере генерации. Кнопка «Копировать» появляется у блока кода, когда ответ готов. Парсер Marked 17.0.5 поставляется вместе с проектом в `OllamaClient/wwwroot/vendor`.

Для всех режимов достаточно одной модели. Комплект из методички включает `codellama:7b` и `deepseek-coder:6.7b`. При наличии обеих первая выбирается для генерации, вторая для ревью. После загрузки через `ollama pull` нажми «Обновить модели».
